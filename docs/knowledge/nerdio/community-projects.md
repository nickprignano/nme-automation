# Community projects

Other public Nerdio + Terraform work. Useful for comparison; none is endorsed by Nerdio unless noted.

| Project | Notes |
|---|---|
| [Get-Nerdio/NME-Terraform-Provider](https://github.com/Get-Nerdio/NME-Terraform-Provider) | Nerdio's official provider. See [terraform-provider.md](terraform-provider.md). |
| [roanp/NerdioTerraform](https://github.com/roanp/NerdioTerraform) | Rebuilds Nerdio's Azure resources directly instead of using the Marketplace. The app package comes from Nerdio support. Lists required roles. |
| [roanp/NerdioTerraformUnofficial](https://github.com/roanp/NerdioTerraformUnofficial) | Unlicensed fork/port of the `MB-External/NME-Terraform` layout (`modules/service`, `modules/ccl`, `modules/rti`, `root/`). Deploys NME core, CCL (Cloud PC Connectivity / Log) and RTI (Real-Time Insights) sub-modules, plus offline package zip support. Uses `local-exec` PowerShell (`Az.Accounts`, `Az.Websites`, `SqlServer`) and `null_resource` with `timestamp()` triggers on every apply; reference only (no license). |
| [oWretch/Nerdio-Terraform](https://github.com/oWretch/Nerdio-Terraform) | Unlicensed early predecessor to `roanp/NerdioTerraform`: builds NME's Azure resources (App Service, SQL, Key Vault, Automation, VNet, private DNS, Shared Image Gallery, Entra app) in Terraform, then requires manually requesting the application zip from Nerdio support and granting admin consent in the portal. |
| [MB-External/NME-Terraform](https://github.com/MB-External/NME-Terraform) | Automates the install end to end: app settings, Key Vault, SQL bootstrap, then app code from Nerdio's package API via Kudu zip deploy. Consent stays manual. See [platform.md](platform.md#install-step-manual-marketplace-path). **Tracked prior art for `modules/nerdio-core`**, which is built in parallel: the curator watches its commits, so diff new app settings or package steps against ours. It has no license, so we reuse facts (setting names, API calls) and never its code. Differences: it runs PowerShell on the Terraform machine with a service principal secret and creates SQL users by script; ours deploys from an Automation job inside Azure and uses an Entra group as the SQL admin. |
| [pc-dok/N4K-Github-AVD-Packer](https://github.com/pc-dok/N4K-Github-AVD-Packer) | AVD image builds with Packer and GitHub Actions. No Nerdio integration. |
| [microsoft/terraform-provider-msgraph](https://github.com/microsoft/terraform-provider-msgraph) | Official generic Graph provider (preview, v0.6.0), for Entra/Intune gaps azuread doesn't cover. See [../stack-options.md](../stack-options.md#tool-verdicts). |
| [Get-Nerdio/NMW](https://github.com/Get-Nerdio/NMW) | Nerdio's own repo: `templates/mainTemplate.json`, the update runbook that uses the package API, `intune-policies/` (baselines, ASR, compliance, CA, Defender, firewall), `azure-custom-roles/nme-custom-role.json` (least-privilege role) and Windows scripted actions (screen capture protection, RDP Shortpath, clipboard). See [../security/README.md](../security/README.md). |
| [aaronparker/nerdio](https://github.com/aaronparker/nerdio) | PowerShell Scripted Actions (`/actions`), Shell Apps (`/shell-apps`), Pester image tests (`/tests`) and sample NME deployment templates (`/nme`) by Aaron Parker (stealthpuppy, Nerdio). **GPL-3.0 licensed** (reference only; do not copy code into this Apache-2.0 repo). Focuses on inside-the-guest customization and Nerdio Scripted Actions rather than declarative Terraform control-plane management. |
| [EUCPilots](https://github.com/EUCPilots) ([eucpilots.com](https://eucpilots.com/)) | Aaron Parker's EUC automation hub: [`evergreen-module`](https://github.com/EUCPilots/evergreen-module) (MIT; live vendor version/URL resolution for Windows apps), [`vcredist`](https://github.com/EUCPilots/vcredist) (MIT; Visual C++ Redistributable installer automation), [`evergreen-packages`](https://github.com/EUCPilots/evergreen-packages) (package definitions for Nerdio UAM Shell Apps and Intune Win32 apps) and Evergreen Workbench. Complementary to this kit: we call `Evergreen` and `VcRedist` optionally from `packer/avd-win11` ([../packer/avd-image.md](../packer/avd-image.md#evergreen-and-vcredist-optional)). |
| [WayneBellows/fslogix-healthcheck](https://github.com/WayneBellows/fslogix-healthcheck) | MIT-licensed read-only PowerShell diagnostic script for FSLogix on AVD/RDS session hosts by Wayne Bellows (Nerdio). Audits registry settings against Microsoft best practices, checks Defender AV exclusions, tests SMB/TCP 445 connectivity and Kerberos, detects stale locks and temporary profiles, and writes a self-contained HTML report with optional guided fixes. Good candidate to run as a Nerdio Scripted Action on session hosts. |
| [virtualmanc/nerdioscripts](https://github.com/virtualmanc/nerdioscripts) | Unlicensed collection of Nerdio PowerShell Scripted Actions and API helper scripts by Neil McLoughlin (Nerdio): Windows 11 25H2 in-place upgrade (`25H2Upgrade`), Scripted Actions backup and restore via the Nerdio REST API (`scriptedactionsbackup.ps1`, `scriptedactionrestore`), OS disk expansion (`expand_os_disk.ps1`) and Office deployment (`deployoffice.ps1`). Reference only (no license); our kit declares Scripted Actions directly in Terraform (`nme_scripted_action` in `modules/nerdio-config`). |
| [Get-Nerdio/NMM](https://github.com/Get-Nerdio/NMM) | Nerdio's public templates and scripts for Nerdio Manager for MSP (NMM). Separate product from NME, unlicensed (reference only). |
| [WayneBellows/euc-prompt-library](https://github.com/WayneBellows/euc-prompt-library) | Read-only AI agent prompts for Azure Virtual Desktop and Nerdio Manager administrators by Wayne Bellows (Nerdio). |
| [aaronparker/m365apps](https://github.com/aaronparker/m365apps) and [aaronparker/defaults](https://github.com/aaronparker/defaults) | Aaron Parker's Intune Win32 Microsoft 365 Apps packaging workflow and Windows enterprise OS/default-user profile customization module for physical PCs and virtual desktops. See also his [Evergreen Workbench GA announcement](https://stealthpuppy.com/evergreen-workbench-release/) and Nerdio Shell Apps automation series ([Part 1](https://stealthpuppy.com/nerdio-shell-apps-p1/), [Part 2](https://stealthpuppy.com/nerdio-shell-apps-p2/), [Part 3](https://stealthpuppy.com/nerdio-shell-apps-p3/)). |
| [Awesome Azure Virtual Desktop](https://schmitt-nieto.com/blog/awesome-azure-virtual-desktop/) and [Awesome Azure Local](https://schmitt-nieto.com/blog/awesome-azure-local/) | Curated reference lists of AVD, Nerdio and Azure Local community tools and guides maintained by Cristian Schmitt Nieto. |
| [Azure/FederalAVD](https://github.com/Azure/FederalAVD) | Microsoft's official MIT-licensed **Bicep** deployment and operations toolkit for native AVD across Azure Commercial, Azure Government (GCC High / DoD), Azure Government Secret, and Azure Government Top Secret (networking, private DNS, FSLogix, Compute Gallery/image building, host pools, and monitoring). Unlike this kit (`nerdio-hcl`), it is Bicep-only and deploys native AVD directly without Nerdio Manager, Terraform, OpenBao, or the setup chatbot. Tracked in `sources.toml` as sovereign-cloud AVD reference prior art. |
| [Get-Nerdio/NME-Terraform](https://github.com/Get-Nerdio/NME-Terraform) | Nerdio's official Terraform module (`modules/service` + `root/`) for deploying NME core infrastructure (App Service, SQL, Automation, Key Vault, VNet/PEs, Entra app, App Insights). Unlicensed (reference only). Uses `local-exec` `pwsh` (`Az.Accounts`, `Az.Websites`, `SqlServer`) on the caller's machine; does not deploy AVD spoke networks, FSLogix storage, Packer images, Stage 2 `nerdio/nme` configuration, readiness preflight, or a setup UI. |
| [Get-Nerdio/NME-SE](https://github.com/Get-Nerdio/NME-SE) | Nerdio Sales Engineering repo containing `preflight/`, `Check-NmeInstallPerms.ps1`, `NmeNetworkTest.ps1`, `autoscale/`, `modeler-avd/`, `nerdio-management-aa/`, and `scripted-actions/`. Unlicensed (`Get-Nerdio`, reference only); useful for cross-checking preflight and permission requirements. |
| [Get-Nerdio/NerdioManagerPowerShell](https://github.com/Get-Nerdio/NerdioManagerPowerShell) and [Get-Nerdio/intune-baseline](https://github.com/Get-Nerdio/intune-baseline) | Official `Get-Nerdio` AutoRest-generated PowerShell module (`v1.3.1-preview`) for the NME REST API and Nerdio's Microsoft Intune baseline configurations. Reference only. |
| [Azure/avdaccelerator](https://github.com/Azure/avdaccelerator) and [Azure/terraform-azurerm-avm-ptn-avd-lza-managementplane](https://github.com/Azure/terraform-azurerm-avm-ptn-avd-lza-managementplane) | Microsoft's MIT-licensed AVD Landing Zone Accelerator (Bicep) and Terraform Azure Verified Modules (AVM pattern + resource modules for host pools, workspaces, scaling plans, insights, and session hosts). Manage native AVD directly without Nerdio Manager or `nerdio/nme`. |
| [WayneBellows/inch](https://github.com/WayneBellows/inch) | MIT-licensed collection of lab-tested, read-only AI agent prompts, `SKILL.md` skills (`avd-hosts-left-running`, `nerdio-rest-api`, `nme-scripted-actions`, `nme-shell-apps`, `session-host-script-check`), and rules for Day-2 AVD and Nerdio Manager operations across Codex, Copilot, Cursor, Claude Code, and Gemini CLI. Complementary to this kit's Day-0/Day-1 setup chatbot (`assistant/`). |
| [WayneBellows/nerdio-healthcheck](https://github.com/WayneBellows/nerdio-healthcheck) and [WayneBellows/nerdio-savings-estimate](https://github.com/WayneBellows/nerdio-savings-estimate) | Read-only PowerShell tools (no license; reference only) using the NME REST API and Azure Cost Management to produce an NME best-practice HTML health check and reconstruct auto-scale compute savings. Complementary post-deploy reporting; we avoid duplicating this in `nerdio-hcl`. |
| [WayneBellows/fslogix-cleanup-private-endpoint](https://github.com/WayneBellows/fslogix-cleanup-private-endpoint) | MIT-licensed Nerdio Manager scripted actions to delete old FSLogix profiles behind a private-endpoint Azure Files share without a Hybrid Runbook Worker. |
| [BG-Red/dashflow](https://github.com/BG-Red/dashflow) | MIT-licensed self-hosted multi-tenant AVD + Nerdio dashboards (Bun + Postgres container) supporting Azure, Lighthouse, Partner Center (GDAP), and Nerdio Manager with scoped customer viewer roles. Complementary observability surface; we avoid building custom reporting UIs in `nerdio-hcl`. |
| [schmittnieto/nerdio-scripted-actions](https://github.com/schmittnieto/nerdio-scripted-actions) | MIT-licensed curated community Scripted Actions for NME complementing `Get-Nerdio/NMW`. |
| [flowdevs-io/nerdio-nmm-mcp](https://github.com/flowdevs-io/nerdio-nmm-mcp) and [marcosartiaga/nmm-install-preflight](https://github.com/marcosartiaga/nmm-install-preflight) | NMM (MSP) ecosystem tools: an MCP server for NMM (custom license) and an MIT-licensed NMM pre-install checker (archived; moved to `MSP-Sales/nmm-preinstall-checker`) checking App Service B2 / SQL S1 region eligibility. |

When adding a new project, record its license, what it does, and how it differs from this kit.
